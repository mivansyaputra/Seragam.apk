Pengambilan seragam

Tanggal
Siap. Cari siswa dengan NISN atau nama.

Transaksi

Rekap per siswa

Rekap stok seragam

Isi stok awal di tab Data. Stok awal 0 = stok tidak dicek.

Pembelian seragam

Siap. Cari pembeli dengan NISN atau nama.

Riwayat pembelian

Pesanan menunggu stok (indent)

Otomatis tercatat saat stok kurang dan Anda memilih "catat sebagai pesanan". Klik "penuhi" setelah stok ditambah di tab DATA.

1. Data siswa

Tempel dari Excel dengan kolom: NISN, Nama, Kelas (kolom ke-4 Status boleh dikosongkan; isi NONAKTIF untuk memblokir). Siswa dengan NISN sama akan diperbarui.

2. Daftar barang seragam

Atur sendiri kode barang, jenis, ukuran, harga (kosong = ikut harga jenis), stok awal (0 = stok tidak dicek), dan keterangan. Mengubah kode, jenis, atau ukuran ikut memperbarui riwayat lama.

Impor banyak barang dari Excel

Kolom: Kode barang, Jenis, Ukuran, Harga, Stok, Keterangan. Kode yang sudah ada akan diperbarui.

Harga jual (opsional, untuk menu BELI)

Kosongkan jika belum ada harga; nota tetap bisa dicetak tanpa harga.

3. Cadangan otomatis & petugas

Pilih folder (misalnya flashdisk). Setiap SIMPAN, data otomatis disalin ke sana. Hanya di Chrome (laptop/komputer). Safari dan iPhone belum mendukung: pakai Unduh cadangan.

Nama petugas (tercetak di bukti)

4. Cadangan manual

Data tersimpan di komputer/aplikasi ini (versi flashdisk: folder DataSeragam di sebelah file .exe). Simpan cadangan tiap selesai hari. Kalau dibuka langsung lewat browser, jangan memindah/mengganti nama file HTML ini.
